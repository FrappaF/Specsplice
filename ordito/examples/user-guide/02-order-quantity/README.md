# Order quantity

Open this folder with **Open Project**. The starter model has the predicate `quantity > 0` and eight independent cases. You will prepare source changes during the exercise. Add the two cases from L12, then review, verify, apply and undo the proposed changes.

Work on a copy of the entire folder, including hidden `.ordito` data. Make changes in Specsplice and keep the original archive so you can start over.
