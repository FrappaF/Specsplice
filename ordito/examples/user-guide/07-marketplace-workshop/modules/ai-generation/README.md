# Marketplace From Diagrams to Code

This starter project for L18 contains the Specsplice model and seven independent cases. Copy the entire folder, including `.ordito`, and open the copy with **Open Project**. Review **Checkout**, **Returns** and the **Marketplace · Dependencies** view. Then start generation for both features from **Code** with the JavaScript on Node.js ESM profile. You can start over from a fresh copy of the model and cases after applying the generated code.

For **Checkout**, two units at 1,250 cents each produce an **Order** worth 2,500 cents. **Returns** uses the same **Order** contract. A return is accepted on day 30 and falls outside the window on day 31. The exercise uses local data and simulated outcomes.
