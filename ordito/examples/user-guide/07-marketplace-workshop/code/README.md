# Marketplace Starter Code

This is a dependency-free Node.js ESM codebase. Run `npm test` to execute seven tests and `npm start` to launch the demo. Choose **Import Codebase** to start exercise L16. The folder includes the source tree and starts without Git history or an imported model.

Work on a copy of the entire folder, including hidden `.ordito` data. Make changes in Specsplice and keep the original archive so you can start over.
