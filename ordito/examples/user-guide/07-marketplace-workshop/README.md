# Marketplace Workshop

Follow Part II of the guide, from L1 through L21. Open the project root listed for each lesson.

| Folder | Contents |
| --- | --- |
| `start` | Empty workspace for **Create Project** and building the model from scratch |
| `milestones/01-boundaries` | Saved checkpoint after L3 with an overview, C4 Context and Use Case. Automatic views are still empty. |
| `milestones/02-data-architecture` | Saved checkpoint after L5 with context, goals, C4, ERD and a data schema |
| `solution` | Three features and 18 views across 16 notations |
| `modules/quantity` | Rule template, cases and a solution that sets the maximum to 10 |
| `modules/interactions` | Checkout with an alternative, a reference and an optional notification |
| `modules/states` | Executable flat state machine and independent cases |
| `modules/messaging` | Queue and topic topology and cases |
| `code` | Dependency-free JavaScript module, seven tests and a demo |
| `ai-code` | Codebase with **Checkout** and **Returns**, a shared in-memory store and five tests for L17 |
| `modules/ai-generation` | Model with **Checkout**, **Returns** and seven independent cases for generating the first source files in L18 |

Each module is a standalone exercise in the marketplace domain. The solution contains all 18 views of the store design. The milestones show the model as it was saved at the end of the corresponding lessons, with the same object identities and empty views where you have yet to add details.

Edit the model with Specsplice forms. The deployment, network and data schema document design choices. Work on a copy and keep the original package to repeat the workshop.
