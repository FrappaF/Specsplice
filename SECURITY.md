# Reporting a vulnerability

For a vulnerability in Specsplice, use **Report a vulnerability** in the [GitHub Security tab](https://github.com/FrappaF/Specsplice/security) if available. Otherwise, contact the repository maintainer privately to arrange how to share the details. Keep vulnerability details and sensitive information out of public issues.

Include the affected version or commit, the impact and enough information to verify the issue. For vulnerabilities in upstream VS Code, follow [Microsoft's reporting process](https://aka.ms/SECURITY.md).
