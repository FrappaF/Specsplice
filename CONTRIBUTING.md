# Contributing to Specsplice

Follow the [development guide](ordito/docs/fork-development.md) to set up your clone and start Specsplice. The [architecture overview](ordito/docs/architecture.md) shows where the domain, workbench and Node.js tools live.

## Report a problem

Search the [Specsplice issues](https://github.com/FrappaF/Specsplice/issues) first. Include your Specsplice version or commit, operating system, steps to reproduce, and the expected and observed results. If possible, attach a minimal example with sensitive information removed. Follow the [security reporting process](SECURITY.md) for vulnerabilities.

## Propose a change

Create a branch for your change. Use the Node.js version in [`.nvmrc`](.nvmrc) and run the [checks relevant to your change](ordito/docs/fork-development.md#verify-a-change). In your pull request, describe the problem, what the change does and how you verified it.
